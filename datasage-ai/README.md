# DataSage AI

**Chat with your data. Get insights in seconds.**

Upload a CSV or Excel file and get an instant, auto-generated dashboard —
KPIs, six chart types, an AI-written insights panel, a ChatGPT-style chat
that answers questions grounded in your data, and a one-click executive
PDF report.

```
frontend/   Next.js 15 + TypeScript + Tailwind + Recharts
backend/    FastAPI + Pandas + (optional) OpenAI
```

---

## 1. Run the backend

```bash
cd backend
python3 -m venv venv && source venv/bin/activate   # optional but recommended
pip install -r requirements.txt --break-system-packages   # drop the flag if not using a system Python

cp .env.example .env
# Optional: open .env and set OPENAI_API_KEY to enable real LLM answers.
# Everything works without it — DataSage AI falls back to a built-in
# rule-based analyst (trend detection, top/bottom performers, outliers,
# correlation, linear forecasting, summaries).

uvicorn main:app --reload --port 8000
```

The API is now live at `http://localhost:8000`. Check `http://localhost:8000/api/health`.

## 2. Run the frontend

In a second terminal:

```bash
cd frontend
npm install

cp .env.local.example .env.local
# NEXT_PUBLIC_API_BASE=http://localhost:8000  (already the default)

npm run dev
```

Open `http://localhost:3000`. Upload a spreadsheet, or click **"Try the
sample dataset"** on the landing page for an instant demo with 400 rows
of realistic regional sales data (already bundled in `backend/sample_data/`).

> **Note on production builds:** Next.js resolves the `/api/*` rewrite
> proxy at *build* time, not at server start. If you run `npm run build`,
> make sure `NEXT_PUBLIC_API_BASE` is set in your shell (or `.env.local`)
> **before** the build command, not just before `npm run start`.

## What's implemented

**Landing page** — animated hero, drag-and-drop upload, sample-dataset
button, feature highlights, dark/light theme.

**Dashboard** — Total Rows, Total Columns, Missing Values, Numeric /
Categorical Columns, Duplicate Rows, and an animated Dataset Health Score
ring, computed live on upload.

**Charts** (Recharts + a hand-built correlation heatmap) — Line, Pie,
Bar, Histogram, Correlation Heatmap, Scatter — auto-selected based on
which columns are numeric, categorical, or datetime.

**AI Insights** — a rule-based engine flags trends, best/worst
categories, outliers (IQR method), strong correlations, missing data,
and duplicates. If `OPENAI_API_KEY` is set, chat answers and the report's
executive summary are generated by an LLM grounded in a compact
statistical summary of your data (raw rows are never sent).

**AI Chat** — ask things like *"Which city has the highest revenue?"*,
*"Explain the revenue trend"*, *"Summarize this dataset"*, *"Which
category should we discontinue?"*, *"Forecast next month's sales"*.
Suggested-question chips: Analyze Dataset, Generate KPIs, Find Outliers,
Find Trends, Summarize, Forecast.

**Report Generator** — Executive Summary, Key Insights, Business
Recommendations, Potential Risks, Next Steps, plus a downloadable PDF
(built server-side with ReportLab).

**Extras** — searchable/paginated dataset preview, per-column stats
table, cleaned-dataset CSV download (dedupes rows), recent-uploads
dropdown, light/dark toggle.

## Architecture notes (for judges / future you)

- **In-memory dataset store** (`backend/data_store.py`): zero setup for
  a 24h hackathon, but not persistent across restarts and not safe for
  multiple uvicorn workers. Swap in Redis/Postgres for production.
- **AI is pluggable, not required**: every feature works with zero API
  keys via heuristic analysis (`backend/utils/ai.py`); set
  `OPENAI_API_KEY` to upgrade chat and report narratives to a real LLM
  without changing any frontend code.
- **Chart data, not chart images**: the backend returns JSON shaped for
  Recharts rather than server-rendered Matplotlib images, so charts stay
  crisp, interactive, and theme-aware on the frontend.
